# Project Structure

The deployable application lives directly in the server root:

```text
./
├── index.php              # Final public entry point
├── install.php            # One-time installer
├── config.example.php     # Example shape for generated config.php
├── .htaccess              # Routing and access protection
├── api/                   # API endpoints
├── admin/                 # Admin panel
├── assets/                # CSS, JS, images, fonts
├── core/                  # Bootstrap, auth, models, database singleton
├── database/              # SQL schema files consumed by install.php
├── uploads/               # Runtime uploads
└── storage/               # Runtime private storage (created by installer)
```

`config.php` and `installed.lock` are generated by `install.php` and ignored by Git.
