# UI UX Skill

## Rules

- Keep Persian RTL consistency.
- Keep UI consistent with existing admin theme.
- Reduce clicks.
- Make forms easier.
- Use clear labels.
- Use useful empty states.
- Avoid visual clutter.
- Avoid debug logs in UI.
- Use clean Persian error/success messages.
- Preserve responsive behavior.

## Review Areas

- Navigation
- Sidebar grouping
- Dashboard cards
- Tables
- Filters
- Search
- Forms
- Modals
- Buttons
- Empty states
- Error messages
- Mobile layout
- Accessibility basics

## Persian UI Messages

Use clear messages like:

- رکوردی یافت نشد.
- اطلاعات با موفقیت ذخیره شد.
- امکان انجام این عملیات وجود ندارد.
- مقدار واردشده معتبر نیست.
- دسترسی شما برای این بخش کافی نیست.
