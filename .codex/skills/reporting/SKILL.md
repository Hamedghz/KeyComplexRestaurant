# Reporting Skill

## Rules

- Define each metric clearly.
- Separate gross, net, discount, tax, return, and payable values.
- Use consistent date ranges.
- Validate filters.
- Avoid misleading totals.
- Support CSV export where useful.
- Use pagination for large reports.
- Show empty states.
- Keep reports actionable.

## Report Structure

## Summary
Main result.

## Key Metrics
Numbers and definitions.

## Breakdown
By date, user, role, department, product, category, city, or module.

## Risks
Data gaps, unusual values, missing records, or suspicious trends.

## Recommended Actions
Concrete operational suggestions.
